Brancher Frottement au téléphone

Pour que la pause s'affiche toute seule quand tu ouvres une appli.

Lien à utiliser dans l'automatisation (remplace instagram par l'appli voulue) :

iPhone — app Raccourcis
  1. Ouvre l'appli Raccourcis, onglet Automatisation, puis + (Nouvelle automatisation).
  2. Choisis App, coche Est ouverte, sélectionne Instagram, puis Exécuter immédiatement.
  3. Touche Nouveau raccourci vide, cherche l'action Ouvrir des URL et colle le lien ci‑dessus.
  4. Valide. Désormais, ouvrir Instagram affichera d'abord la pause 🧘
  5. Bonus : dans Safari, bouton Partager → Sur l'écran d'accueil pour avoir Frottement comme une vraie appli.
Android — app MacroDroid (gratuite)
  1. Installe MacroDroid depuis le Play Store et ouvre-la.
  2. Ajouter une macro → Déclencheur : Application lancée/fermée → coche Instagram, « Application lancée ».
  3. Action : Ouvrir un site web → colle le lien ci‑dessus.
  4. Enregistre la macro. Pense à autoriser MacroDroid à « s'afficher par-dessus » si Android le demande.
  5. Bonus : dans Chrome, menu ⋮ → Ajouter à l'écran d'accueil.
